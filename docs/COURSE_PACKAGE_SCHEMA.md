# Portable FluencyCards Course Package

The canonical exchange format is provider-neutral JSON:

```json
{
  "course_id": "english-for-khmer",
  "version": "1.0.0",
  "title": {"en": "English for Khmer Speakers", "kh": "..."},
  "lessons": [
    {
      "id": "M01",
      "module_number": 1,
      "lesson_number": 1,
      "title": {"en": "Good Morning", "kh": "..."},
      "cards": [],
      "conversation": [],
      "review": []
    }
  ]
}
```

This package can be generated by any LLM, another developer, or the local CSV builder. Cloudflare stores imported packages as immutable draft versions. AI review creates suggestions; it never overwrites a course automatically.
