# FluencyCards Pedagogical Standard 1.0

## Core cycle
Teach → Practice → Assess → GO/NO-GO → App-generated retraining → Reassess → Master → Audit later.

## Mastery
There are no traditional passing grades. Scores are diagnostic. A lesson is complete only when every required mastery domain is GO.

- Comprehension
- Recall without seeing the answer
- Conversation in context
- Pronunciation comprehensibility, not accent elimination

## Retraining
The application generates retraining from failed skills. An instructor assists with app-generated retraining and gives human feedback. The instructor does not assign punitive retraining.

## Audits
The default audit occurs every ten lessons. A failed retention check preserves historical mastery but changes current retention status and creates targeted retraining.

States:
- Green: mastered and verified
- Amber: mastered, audit due
- Red: retention failure, retraining required
- Gray: not mastered

## Layout
Every ordinary instructional card, its primary controls, and navigation must fit inside the usable viewport without page scrolling.
