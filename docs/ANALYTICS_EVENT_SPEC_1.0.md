# Analytics Event Specification 1.0

Instructional events:
- activity_started
- activity_attempted
- activity_go
- activity_no_go
- skill_mastered
- lesson_mastered
- audit_started
- audit_skill_go
- audit_skill_no_go
- retraining_generated
- retraining_activity_completed
- retention_restored
- conversation_turn_attempted
- pronunciation_feedback_received

Tutors see learner data only after consent. Course authors see anonymized aggregate data.
